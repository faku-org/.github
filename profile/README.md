## 01 · Qué es este espacio

Faku Org es mi organización personal para construir, probar y publicar software que resuelve problemas concretos.

Acá viven proyectos propios, experimentos y sistemas que mezclan código con pensamiento. No es un catálogo de demos: cada repositorio existe para aprender algo, resolver algo o dejar una herramienta mejor de como la encontré.

## 02 · Cómo construyo

**Entender antes de abstraer.** Prefiero comprender el problema completo antes de agregar otra capa.

**Producto antes que feature.** Una herramienta clara y útil vale más que una lista larga de funciones.

**Diseño como parte del sistema.** La experiencia, el lenguaje y la velocidad también son decisiones técnicas.

**Construir en público.** Los proyectos mejoran cuando sus ideas, límites y decisiones pueden ser revisados.

## 03 · En qué trabajo

### Software para trabajar y aprender

- **Jobit**: buscador de ofertas de trabajo en Uruguay, con foco en oportunidades accesibles para quienes están empezando.
- **LearnIt!**: plataforma para aprender idiomas con una experiencia simple y directa.
- **Clases.uy**: gestión de clases particulares para estudiantes universitarios.

### Productividad y conocimiento

- **Meetily**: asistente de reuniones con transcripción y resumen local, sin depender de la nube.
- **Vaults y herramientas de Obsidian**: sistemas para organizar, sincronizar y extender el conocimiento personal.
- **SearchIt**: herramientas para mejorar el flujo de trabajo de fotógrafos.

## 04 · Stack habitual

**Frontend** - React 19, TypeScript, TailwindCSS v4, Vite, Bun  
**Backend** - Elysia, SQLite, GraphQL  
**Infra** - Linux, GitHub Actions, VPS propio  
**Herramientas** - Obsidian, Git y automatización propia

## 05 · Fuera del código

Música, filosofía política, servidores de Minecraft, economía y preguntas sin respuesta fácil.

Las mejores decisiones de producto suelen aparecer cuando el problema se mira desde más de una dimensión.
